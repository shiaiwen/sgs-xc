# xc 本地开发与发布

线上地址是 `https://xc.95chong.cn/`。Nginx 直接托管服务器上的 `/opt/xc/dist`。

下面的命令都在本项目目录执行。

## 第一次准备

```bash
npm install
```

上传走 SSH，默认目标是 `admin@123.56.3.130`，目录是 `/opt/xc`。

## 本地开发

```bash
npm run dev
```

浏览器打开 `http://localhost:3000/`。

## 发布到服务器

```bash
npm run deploy
```

流程是：

1. 执行 `npm run build`（Next.js 静态导出）
2. 把 `out` 复制成 `dist`
3. 上传 `dist` 到 `/opt/xc/dist`

想保存后自动发布时：

```bash
npm run sync
```

## 环境变量

| 变量 | 默认值 | 作用 |
| --- | --- | --- |
| `XC_SSH` | `admin@123.56.3.130` | SSH 目标 |
| `XC_REMOTE` | `/opt/xc` | 服务器目录 |
