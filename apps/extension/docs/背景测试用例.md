# 背景测试用例

按现在的产品行为写。全局背景关着只铺牌局。皮肤做背景只控制小抄背景这一页出不出来，不改已经设好的图。

单测在 `apps/extension` 下执行。实机要在微端里点。

## 开关

- **B01** 皮肤做背景关掉
  - 步骤：背景面板开着，关掉皮肤做背景。
  - 预期：小抄背景这一页马上收起。桌上、房间列表已经显示的图不动。
- **B02** 皮肤做背景再打开
  - 步骤：接着再打开皮肤做背景。面板还开着，或先关面板再打开。
  - 预期：小抄背景这一页重新出现，排在主题、静态、动态后面，能看见。已经设好的图仍是关掉之前那张。
- **B03** 反复开关
  - 步骤：连续关、开两次以上。
  - 预期：每次关都收起这一页，每次开都重新出现。不会只在第一次有效。
- **B04** 全局背景关掉
  - 步骤：全局背景关着，看首页、房间列表、牌局、旁观。
  - 预期：只有牌局和旁观铺已存的小抄图。房间列表、首页保持游戏原来的画面。
- **B05** 全局背景打开
  - 步骤：打开全局背景，再看房间列表和首页。
  - 预期：这些页面可以铺已存的小抄图。身份演武开局选将那一层不要被盖住。

## 小抄背景页

- **B06** 页签位置
  - 步骤：皮肤做背景开着，打开背景面板。
  - 预期：四个页签是主题背景、静态皮肤、动态皮肤、小抄背景。第四页不被挤出画面。
- **B07** 点收藏设背景
  - 步骤：在小抄背景里点一张不是当前背景的收藏。
  - 预期：第一次点击就换成这张。成功后只有这一张有勾。失败不打勾，并提示背景设置失败，请重试。
- **B08** 详情设为背景
  - 步骤：在皮肤详情点设为背景，先不收藏。
  - 预期：提示成功，并且画面换成这张。不用再去收藏里点一次。
- **B09** 收藏不等于设背景
  - 步骤：只点收藏背景，不点设为背景，也不在小抄列表里点这张。
  - 预期：列表里多一张。当前画面和勾都不因此改变。
- **B10** 删除
  - 步骤：对不是当前背景的收藏点一次右上角叉。
  - 预期：只删这一张。当前正在用的没有叉。点叉不会去设背景。

## 进桌和旁观

- **B11** 重新登录进旁观
  - 步骤：账号里上次设的是小抄收藏，例如陈宫。重新登录后进一局旁观。
  - 预期：一进桌就是这张，不是绿茵赛场。勾在这张收藏上，主题页的绿茵赛场没有勾。
- **B12** 自己打和旁观
  - 步骤：同一张已存背景，分别自己进桌和旁观。
  - 预期：两边都是这张已存图。
- **B13** 详情设完再进桌
  - 步骤：在详情把一张皮肤设为背景，然后进牌局或旁观。
  - 预期：进桌就是刚设的这张，不用再去收藏里点。

## 官方背景

- **B14** 官方背景开
  - 步骤：打开官方背景，看静态皮肤列表。
  - 预期：没拥有的也列出来，可以选。
- **B15** 官方背景关
  - 步骤：关掉官方背景，再看静态皮肤列表。
  - 预期：回到游戏原来的已拥有列表。
- **B16** 四个页签只有一个勾
  - 步骤：分别在主题、静态、动态、小抄里设一张。
  - 预期：全局面只有最后设的那张有勾。绿茵赛场不会和别的图一起勾着。
- **B17** 动态皮肤
  - 步骤：在动态皮肤里点一张。
  - 预期：设成背景并且会动。面板不自己收起。切走再回来，列表还在，不和静态皮肤叠在一起。

## 房间列表

- **B18** 没开全局
  - 步骤：全局背景关着，从牌局回到房间列表。
  - 预期：房间列表是游戏原来的画面，不留牌局里的小抄图。
- **B19** 开了全局
  - 步骤：打开全局背景，停在房间列表。
  - 预期：房间列表可以是已存的小抄图。
