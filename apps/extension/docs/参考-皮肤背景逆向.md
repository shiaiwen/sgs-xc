## 产品差异（有意保留）

1. 收藏成功文案：参考换肤窗为「自选皮肤」，小抄页为「小抄背景」；本仓库详情与换肤均写「小抄背景」键与页签一致。
2. 牌桌显示：未开全局时已改为仅要求 `gamescene`，与参考 `cB` 一致。
3. 运行时：本仓库仅 TypeScript 构建产物，不加载参考混淆脚本。

## 预期效果（用户可见）

1. 用户点顶栏「换背景 / 皮肤背景」入口，游戏弹出 **wallPaperUI** 大面板，默认能看见官方 **主题背景 / 皮肤背景** 列表。
2. **qF() 为真** 时 **SE** 才会挂扩展页：除官方两页外还有 **zX=`xcLocalBackgrounds`（本地资源）** 与 **zT=`xcSkinBackgroundFavorites`（自选皮肤/收藏）**；**zw() 为真** 时 **Sa** 走 **SJ** 再 **SE**，否则 **Sa** 仍可调 **SE** 但走 **So/Ss** 官方解锁分支。
3. 点收藏页 **zT** → **Sf → Sk → Sq**；列表项 **Sy** 点击 → **oi(resource)**；**qF 假** 只 toast「请先升级VIP并打开个性背景」，无其它反馈。
4. **Sf** 首进若 **zq()** 资源未 loaded，会 **等 Loader** 再重试 Sf；列表空或未就绪见「还没有收藏背景」或「皮肤背景列表尚未就绪」。
5. 点收藏条目写 **paperRes**，牌桌底图更新。
6. 关 **qF** 或摘扩展时 **SL** 恢复 **__xcBackgroundTabLayout** 与原生 **onTabClick**。

## 参考里「面板怎么出来」（SF / Sa / Sv）

| 步骤 | 参考行为 | 本项目 |
|------|----------|--------|
| 入口 | **SF**：取 `scene.topMenu`，**Sv** 包装宿主 **onClickSkin**；点击后若 `wallPaperUI.visible` 则 **Sa** | `wrapTopMenuOpenMethod` + `prepareTopMenu` → **syncWallPaperMenuSa** |
| 无 wallPaperUI | **SF** 直接 `return qR()`，**不**预开面板 | 参考无预开；任何「静默 onClickSkin + visible=false」均为自造，与预期不符 |
| 就绪条件 | **Sa** 轮询：`wallPaperUI.tabGroup.BtnList.length > 0` | **wallPaperMenuForSa** 同等条件，Ug **100ms × 50** |
| skinPaper 关 | **zw()** 假：**So** 恢复官方面板 + 仍可调 **Sa** 里非 SJ 分支 | `extensionOn` / `detachMenu` |
| 另一入口 | **S5** 挂 **BgSetView.prototype.updateList/destroy**（个性背景/设置里另一套 UI） | **未实现** |

### 门控（参考）

- **qF()**：与 **S6/SQ/SE** 绑在一起，语义上等于「皮肤做背景功能开」；关则 **SL**。
- **zw()**：`qR() && Vk?.[…]`，除配置外还依赖 **qR 运行时** 与 **Vk 授权位**；不是单纯的 config 布尔。
- **qR()**：`qi[2]()` 聚合运行时是否允许挂小抄 UI；**SF** 在没 wallPaperUI 时也用 qR() 决定是否继续。

## 「整个面板都不出来」时优先对照

1. **是否走了 create-hidden-menu**：trace 有 `create-hidden-menu` 且用户没再点入口 → 对象可能是 **visible=false** 的 wallPaperUI，参考不会这样预挂。
2. **topMenu 是否找对**：SF 用 `cU.scene.topMenu`；局内若 topMenu 不在 gameScene 上，**Sa 永远等不到 BtnList** → `sa-timeout`。
3. **是否其实是 BgSetView**：设置里「个性背景」可能走 **BgSetView** 而非 topMenu.wallPaperUI；只挂 SF 路径时 **面板能开但没有小抄页** 或 **完全不是同一组件**。
4. **zw 为假**：参考仍可能开官方面板，但 **SJ/SE 不跑**；与「官方两页都没有」不是同一类问题。
5. **zq 未就绪**：主要影响 **Sf 收藏区**，一般不挡整个 wallPaperUI 弹出。


## 与本仓库「效果不对」时优先缺的参考块

| 参考块 | 用户可见差异 |
|--------|----------------|
| **ot + o8 + qF/z6.setEnabled** | 开关变了但 **SF/Sa 不刷新**；DOM 壳与游戏内面板不同步 |
| **S5 BgSetView** | 设置里个性背景 **完全没有** 小抄页/本地页 |
| **SE 里 SQ(zX)+SQ(zT)** | 少「本地资源」页或页签顺序/宽度 **zi** 不对 |
| **zq + Sf 重试** | 切到收藏页 **空白**，过一会才出或一直不出 |
| **SJ + SS/initData** | **zw** 路径下官方皮肤列表/选中态与参考不一致 |
| **Sy 的 qF + oi** | 点了收藏 **没反应** 或只 VIP toast |
| **zw = qR && Vk[0x118d]** | 配置开了但 **从不走 SJ** |
| **qR = qi[2]** | 场景不对时 **SF/Sa 整链不跑** |

产品可不做 **xcLocalBackgrounds** 整页，但 **SE 仍会在参考里 SQ(zX)**；若只做收藏一页，需明确是裁剪而非参考一致。
