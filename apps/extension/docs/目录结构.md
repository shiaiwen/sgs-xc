# apps/extension 目录结构

三国杀 OL「小抄」：微端脚本 + 浏览器 Userscript。业务代码在 `src/`，打包同时产出两种形态。当前包名 `SGSOL`，脚本版本见根目录 `package.json` 的 `version`。

---

## 总览

```
apps/extension/
├── src/                 # 功能源码（主战场）
├── tools/               # 开发、打包、发布脚本与微端壳
├── tests/               # 单元测试
├── docs/                # 工程文档
├── res/ / script/       # 微端壳资源与渲染脚本
├── dist/                # 构建产物（勿手改）
├── release/             # 打包后的安装包 / 清单
├── .reference/          # 逆向/对照参考（本地，一般不提交）
├── .cursor/rules/       # 本仓 Cursor 协作规则
├── package.json         # 脚本版本 + npm scripts
├── vite.*.config.ts     # Electron / Userscript / UI 沙箱构建
├── main.cjs 等          # 微端壳入口与共享模块（根目录 CJS）
└── README.md            # 开发与发版总览
```

| 路径 | 用途 |
| --- | --- |
| `src/entries` | 微端 / 浏览器脚本入口 |
| `src/core` | 启动、配置装配 |
| `src/features` | 游戏功能模块 |
| `src/adapters` | 游戏运行时与平台适配 |
| `src/runtime` | 生命周期、事件总线、补丁 |
| `src/ui` | 小抄面板（Vue） |
| `src/config` | 配置 schema / 存储 |
| `tools/` | 本地开发、打包、部署 |
| `tools/release-app-shell` | 随微端发布的壳程序 |
| `docs/发版.md` | 发版步骤（偏门户侧） |
| `README.md` | 开发与线上发布总览 |

## `src/` 源码结构

### `entries/` — 双端入口

| 文件 | 说明 |
| --- | --- |
| `electron.ts` / `electron-bootstrap.ts` | 微端注入入口与启动 |
| `userscript.ts` | 浏览器 Userscript 入口 |

### `core/`

| 文件 | 说明 |
| --- | --- |
| `bootstrap.ts` | 统一启动：装配配置、功能、UI |

### `config/`

| 文件 | 说明 |
| --- | --- |
| `config-schema.ts` | 配置字段定义 |
| `config-storage.ts` / `config-store.ts` | 持久化与运行时配置 store |

### `adapters/` — 平台与游戏桥

把「游戏内部对象 / 消息 / 设置」适配成小抄可用的接口，屏蔽微端与浏览器差异。

| 文件 | 大致职责 |
| --- | --- |
| `platform.ts` | 平台抽象 |
| `electron-platform.ts` / `userscript-platform.ts` | 两端实现 |
| `game-message-adapter.ts` | 游戏消息适配 |
| `micro-client-message-source.ts` | 微端消息源 |
| `laya-object-locator.ts` | Laya 对象定位 |
| `server-proxy-protocol-hook.ts` | 服务端代理协议钩子 |
| `browser-settings.ts` / `card-config-source.ts` | 浏览器设置与卡牌配置源 |

### `runtime/` — 运行时基础设施

| 文件 | 说明 |
| --- | --- |
| `game-event-bus.ts` | 游戏事件总线 |
| `game-lifecycle-events.ts` / `lifecycle.js` | 生命周期 |
| `wait-for-game-runtime.js` | 等待游戏运行时就绪 |
| `method-patch.ts` | 方法补丁 |
| `game-account-session.ts` | 账号会话 |
| `micro-client-focus.ts` | 微端焦点 |
| `mingpai-trace.ts` | 明牌追踪调试 |

### `features/` — 功能模块

每个子目录一般是「controller + 业务逻辑 + 可选 index 导出」。

| 目录 | 功能概要 |
| --- | --- |
| `mingpai/` | 明牌核心：引擎、区域、图模型（`graph/`）、规则（`rules/`）、预览 |
| `shanhetu/` | 山河图：地图、换将、战法、商店、剧情等 |
| `extra-assist/` | 额外辅助（南华、裴秀路线、许邵、全羽、醉风等） |
| `skill-assist/` | 技能辅助面板与点数计算 |
| `auto-task/` | 自动任务领取/执行 |
| `auto-bot/` | 自动机器人（房间、酒馆、百胜等） |
| `auto-hg/` | 自动相关（换将等流程） |
| `ai-player/` | AI 代打与昵称同步 |
| `block-effects/` | 屏蔽特效、跑马灯、势力口号等 |
| `cards/` | 手牌标签、排序、官服牌面、铁索等 |
| `deck-record/` | 牌堆记录 |
| `recent-cards/` | 最近卡牌 |
| `seat-display/` | 座位状态与显示 |
| `countdown/` | 倒计时秒数 |
| `turn-status/` | 回合状态条数据 |
| `room-filter/` | 经典场房间过滤 |
| `identity-drill/` | 身份演练选将 |
| `skin-background/` | 皮肤/自定义背景 |
| `discount-recharge/` | 折扣充值 |
| `gift-code/` | 礼包码 |
| `runtime-search/` | 运行时搜索 |
| `update-notice/` | 更新提示与清单 |

`mingpai/` 再细分：

```
mingpai/
├── mingpai-engine.ts / mingpai-controller.ts   # 引擎与控制器
├── mingpai-zones.ts / mingpai-queries.ts       # 区域与查询
├── graph/                                      # 卡牌图、候选、移动流水线
└── rules/                                      # 手牌来源标签、探阙、移动规则等
```

### `ui/` — Vue 面板

挂载入口：`mount-xiaochao-app.ts` → `App.vue`。

| 子目录 | 内容 |
| --- | --- |
| `panel/` | 面板壳、拖拽、Tab、布局 |
| `settings/` | 各设置分区（自动任务、屏蔽、皮肤、山河图等） |
| `cards/` | 牌堆记录、技能辅助、手牌面、回合状态条 |
| `dialog/` / `toast/` / `tooltip/` | 通用对话框、Toast、Tooltip |

## 和 monorepo 的关系

本目录是 `sgs-xc` monorepo 里的 `apps/extension`。发版时常联动：

- `apps/portal`：下载页与 `downloads` 静态文件
- `apps/server`：版本 API（如 `https://95chong.cn/api/xiaochao-version`）

细节以 `README.md` 与 `docs/发版.md` 为准；若两处路径表述不一致，以当前 monorepo 根目录脚本为准。
