# 逆向参考包刷新

本文说明如何把官方微端 zip 里的小抄脚本解到本地只读镜像，并同步官网更新日志。供人工对照和交给 Agent 执行，**不参与小抄运行时**。

---

## 目标

- 从 zip 解出 `app/xiaochao.js`，写入 `.dev-data/appbak/`
- 生成可读版 `xiaochao-pretty.js` 与 `REFERENCE_MANIFEST.json`
- 拉取 `https://log.xiaochao.org/updates.txt`，与 zip 内版本对比

对照行为是需求来源，**不得**把 `xiaochao.js` 当作小抄运行依赖。

---

## 权威来源（优先级）

1. **官方 zip**  
   默认：`D:\workspace\sgs-xc\apps\extension\.reference\xiaochao-1.6.47-weiduan-1.1.80.zip`（zip 放在 `.reference/` 根下；产物仍写 `.dev-data/appbak/`。勿与禁止使用的 `.reference/app-bak/xiaochao.js` 混淆）  
   可通过环境变量 `XIAOCHAO_REFERENCE_ZIP` 或命令行第二个参数覆盖。

2. **官网日志**  
   `https://log.xiaochao.org/` → `updates.txt`  
   日志版本**新于** zip 内 `@version` 时，以日志里多出来的版本说明为准。

3. **禁止**  
   - 使用 `apps/extension/.reference/app-bak/xiaochao.js`（旧 1.5.71）  
   - 在 `src/features/**` 里依赖或注入参考脚本

工作区规则：`/.cursor/rules/reference-xiaochao-zip.mdc`

---

## 命令

在 `apps/extension` 目录：

```bash
npm run refresh:reference
```

等价：

```bash
node tools/refresh-reference-reverse.js
node tools/refresh-reference-reverse.js "D:/path/to/xiaochao-xxx.zip"
```

## 产出（均在 `.dev-data/appbak/`，不进 git）

| 文件 | 说明 |
| --- | --- |
| `xiaochao.js` | zip 内混淆脚本 |
| `xiaochao-pretty.js` | js-beautify 后，便于 grep |
| `updates.txt` | 官网更新日志 |
| `REFERENCE_MANIFEST.json` | 刷新时间、zip 路径、脚本版本、SHA256、日志最新版 |

脚本若提示 zip 版本低于日志最新版：应换更新的 zip，或对照 `updates.txt` 中 zip 之后条目改 TypeScript 实现。

## 「自动更新」指什么

| 有 | 无 |
| --- | --- |
| 执行 `refresh:reference` 时用 curl 拉 `updates.txt` | dev 启动、定时任务、bootstrap **不会**自动 refresh |
| | `userscript-dev-auto-reload` 只刷新游戏页里的小抄构建，**不**更新 appbak |

## Agent 标准流程

1. 确认 zip 存在；默认在 `apps/extension/.reference/` 找 `xiaochao*.zip`，或向用户要路径。
2. 在 `apps/extension` 执行 `npm run refresh:reference`，保留终端输出。
3. 读 `REFERENCE_MANIFEST.json`，汇报 `scriptVersion` 与 `changelogLatestVersion` 是否一致。
4. 若任务涉及具体功能：在 `xiaochao-pretty.js` 与 `updates.txt` 检索，结论写在回复里；**默认不改** `src/features/**`。
5. 仅当锚点行号变化时更新 `tools/reference-reverse-index.md`。
6. **不要** `git add .dev-data/`；**不要**未经用户要求执行 `npm run build` / pack。

```text
执行：cd apps/extension && npm run refresh:reference（zip 默认 `.reference/xiaochao-1.6.47-weiduan-1.1.80.zip`，可设 XIAOCHAO_REFERENCE_ZIP）。

读 REFERENCE_MANIFEST.json 与 updates.txt；pretty 在 .dev-data/appbak/xiaochao-pretty.js。勿用 .reference/app-bak。对照规则 reference-xiaochao-zip.mdc、reference-reverse-index.md。

交付：是否 refresh 成功、两版本是否落后、检索结论（若有）、是否改动非 .dev-data 文件。
```
