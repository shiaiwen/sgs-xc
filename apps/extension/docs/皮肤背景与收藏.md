# 皮肤做背景、收藏与小抄页

说明收藏、设为背景、小抄页签的行为、存储与进度。逆向笔记见 [参考-皮肤背景逆向.md](./参考-皮肤背景逆向.md)。

## 用户侧概念

- **设为背景**：当前皮肤大图写入账号 `paperRes`，并在牌桌层显示自定义底图。
- **收藏背景**：写入收藏列表，在背景面板「小抄背景」里点选；**不会**自动变成当前背景。
- **皮肤做背景**：设置项 `skin.skinPaper`。关闭时仍可收藏；设背景会拦截并提示先打开该开关；底图与小抄页签不生效。
- **应用到所有模式**：设置项 `skin.allPaper`。开启后大厅等也可显示皮肤底图；关闭时主要在牌桌内显示。

## 待办

- **T01** 设为背景后存下来的是临时地址
  - 现象：从收藏设背景时，图片先转成临时地址再画，存进配置的也是这个临时地址。
  - 影响：重启游戏后临时地址失效，背景可能不显示。第四个面板里当前背景的选中状态也对不上收藏里的原地址。
  - 做法：存原图地址，画的时候用临时地址。渲染器记住临时地址对应的原图地址，重新加载同一张图时不重画。
  - 相关：`skin-paper-controller.ts` 的 `applyBackground`、`skin-background-renderer.ts` 的 `setBackground`
  - 代码：完成 · 实机：未测 · 重启游戏后看背景和选中状态是否还在

## 小抄背景页签与开关联动（F31）

页签只跟 **`skin.skinPaper`** 联动，不看「有没有收藏」。**`skin.allPaper`** 只影响底图显示范围，不单独控制页签有无。

- **打开开关**：`onSwitchChanged` → `syncWallpaperMenu` → 背景面板 `attachMenu`，出现「小抄背景」页。
- **关闭开关**：对已挂载面板 `detachMenu`，去掉页签；若在用小抄页则切回官方第一页；自定义底图隐藏。
- **仅开官方背景、关皮肤做背景**：不挂小抄页签。
- **两个开关都关**：壁纸 UI sync 退出，官方面板 restore。

实现：`skin-paper-controller` 的 `menuExtension`；`official-background-controller` 的 `extensionOn`、`detachExtensionFromKnownMenus`。

实机：大厅打开背景面板 → 关「皮肤做背景」→ 页签应马上没 → 再开 → 再开面板应恢复。

曾不稳定的原因：关开关时 `sync` 在壁纸钩子未就绪会直接 return，页签摘不掉；延迟 `prepareTopMenu` 可能在关开关后又 attach；detach 后 `tabBound` 未清导致再次 attach 绑不上。已在 `official-background-controller` 与 `skin-background-favorites-tab` 修。

## 设为背景（实现摘要）

**入口**：详情「设为背景」、换肤悬停图标、小抄页点击条目。

**流程**：校验资源 → 须开皮肤做背景 → 关详情窗 → 可 blob 拉原画 → `setBackground` 写 `paperRes` → `syncVisibility` → 成功提示。

**显示**：见 `const/paper-background-visibility.ts`；未开全局需有 `gamescene`；开全局时 `ModeScene` 等藏场景底以免叠两层。

## 收藏背景（实现摘要）

竖版、视频皮不支持。开关关着也能写入收藏；设为背景仍须开开关。`addFavorite` 写 `账号::XC_SKIN_BACKGROUND_FAVORITES`，**不**自动 `setBackground`。

## 持久化

- 当前背景：`{账号}::paperRes`
- 收藏：`{账号}::XC_SKIN_BACKGROUND_FAVORITES`
- 微端双写 `shared.json`；并与 `XC::skinBackground::{账号}` 单文档同步（ST-09）
- 官方壁纸选择：`::XC_OFFICIAL_BACKGROUND_CHOICE`

**和账号的关系**

- 小抄里「皮肤做背景 / 官方背景 / 全局背景 / 皮肤解锁」等开关：按**登录账号分桶**存在配置里，换号会换一套开关默认值或该号已保存的值。
- `paperRes`、收藏列表：按**游戏 clientId** 写键名；读不到 clientId 时退回登录名。换号后应看到该号的背景和收藏，不会跟上一号串。
- 若收藏有、页签没有：先看「皮肤做背景」是否打开，再在大厅或局内**点开一次右上角背景面板**，页签是在面板挂上时插入的，只开开关不打开面板有时看不到。
- 若页签有、列表空或「列表尚未就绪」：多半是背景面板里**皮肤列表 UI 类型还没初始化**，只开「皮肤做背景」、未开「官方背景」时以前常出现；现已在挂页签前调用 `onShowSkinitems` 预热。仍空则看控制台 `favorites-item-constructor-missing`，并确认 `shared.json` 里该账号 `::XC_SKIN_BACKGROUND_FAVORITES` 有数据。

## 原则

1. 收藏不等于设背景，除非产品单开一条路径。
2. 勿 destroy 官方 panel 子节点。
3. 页签组用 `resolveWallPaperTabGroup`，空则不读属性。
4. 只改 `src` 须构建后微端才变。
5. 遵守底图/原型包装约束，避免黑屏。
