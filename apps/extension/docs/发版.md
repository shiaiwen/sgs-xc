# 发版

小抄版本是注入到微端里的脚本版本。它写在工程根目录 `package.json` 的 `version`，打包后出现在 `xiaochao.js` 头部的 `@version` 和线上清单里。微端自己的版本与此无关，发版时不改、也不看它。

线上清单是 `https://xc.95chong.cn/downloads/manifest.json`。下载页是 `https://xc.95chong.cn/downloads`。客户端按清单里的小抄版本逐段比较，远程更大才提示更新。新版本必须大于当前线上版本，否则已注入旧脚本的客户端不会弹更新，只能手动安装 `wd-xc.zip`。

## 步骤

1. 修改 `d:\workspace\sgs-extension\package.json` 的 `version`。

2. 在 `d:\workspace\sgs-extension` 执行：

```bash
npm run pack
npm run copy:portal
```

`npm run pack` 先用 Vite 构建 `dist/electron/xiaochao.js`，再生成：

| 本地文件 | 含义 |
| --- | --- |
| `release/wd-xc.zip` | 手动安装包 |
| `release/app.zip` | 自动更新包 |
| `release/xiaochao-manifest.json` | 清单，`version` 等于上面的小抄版本，并带 `app.zip` 的 sha256 |

`npm run copy:portal` 把这三个文件拷到 `d:\workspace\portal\public\downloads`。清单在网站上的文件名是 `manifest.json`。

1. 在 `d:\workspace\portal` 执行：

```bash
npm run deploy
```

这一步会 `next build`，再通过 SSH 把站点同步到 `admin@123.56.3.130:/opt/xc/dist`。终端出现「已同步到 admin@123.56.3.130:/opt/xc/dist」后，下载页和清单才是新版本。

1. 到小抄服务端项目，更新返回的版本号信息

```bash
npm run deploy
```

## 线上地址

| 地址 | 内容 |
| --- | --- |
| `https://xc.95chong.cn/downloads` | 下载页 |
| `https://xc.95chong.cn/downloads/manifest.json` | 清单 |
| `https://xc.95chong.cn/downloads/app.zip` | 自动更新包 |
| `https://xc.95chong.cn/downloads/wd-xc.zip` | 手动安装包 |

## 总结发版命令

```sh
# 小抄项目构建
npm run pack:portal
# 上传到门户服务器上应用的downloads目录， 如果门户代码有更新执行 deploy
npm run deploy:downloads 
# 更新小抄服务端的接口的返回数据
npm run deploy
```

## 微端更新是否无感

**否。** 正式微端走 `tools/release-app-shell/micro-client-update.js`：

| 步骤 | 会不会打扰用户 |
| --- | --- |
| GET `https://95chong.cn/api/xiaochao-version` | 后台，无感 |
| 发现新版本 | 弹「是否立即更新？」 |
| 下载 `app.zip` | 进度小窗 |
| 校验 sha256 | 后台 |
| 替换 `resources/app` | 先弹「需要管理员权限」，再弹 **Windows UAC** |
| 用户点否 / 取消 UAC | 弹「更新未应用」，继续用旧版 |

`updates.txt`（`log.xiaochao.org`）只是官网更新日志，供对照逆向，**不参与**本仓库微端更新。

另有一条本地静默路径：启动时 `syncBundledScriptIfNewer` 把安装包内 `xiaochao.js` 同步到 userData（哈希不同就覆盖），**不上网、不弹窗**；这不是线上热更。

游戏壳自带的 `electron-updater`（`AutoUpdaterURL` → 官方 OL 更新源）下载完直接 `quitAndInstall`，与小抄清单无关。

### 若要微端也无感，缺口大致是

1. **脚本级热更**：清单增加稳定的 `scriptUrl`（或从 zip 只抽 `xiaochao.js`）→ 写入 userData → 刷新注入；不写 Program Files → **可免 UAC、可免确认**。
2. **整包更新**：仍要 UAC；最多去掉「是否立即更新」改成自动下完再只留 UAC（仍非完全无感）。
3. 勿给 `appUrl`/`scriptUrl` 乱加会变的 query 当「永久地址」写进客户端常量；下载时可临时加 `t=` 防缓存（当前已如此）。

油猴无感见上文「油猴无感更新」；与微端是两条通道。
