# 卡牌标签对齐清单

参考微端包为 `.reference/xiaochao-weiduan-1.1.94.zip`。小抄脚本使用按官网经典版清单下载并校验的 1.6.84（`.dev-data/appbak/decoded-1684-pretty.js`，来源见 `REFERENCE_MANIFEST.json`）。勾选表示本项目对应的代码路径已实现。实际对局验证另行安排。

- [x] 开关关闭时保留游戏原生标签，不清空游戏的标签数组。
- [x] 独立标签层。手牌、装备和技能窗口共用小抄控件，自动避让原生标签、去重，并在牌面回收时清理。
- [x] 来源标签。从其他角色的手牌区、装备区或判定区取得牌后，按移牌记录标明来源角色。顺手牵羊拿到的暗手牌也显示 `[顺手]武将名`。霸朝移牌缺少技能号时，按已指定的交牌角色和本次移牌补上 `[霸朝]武将名`。公共区域仍按当次公开信息判断。无中生有、雌雄剑等普通暗摸不打来源标签。牌离开本家手牌时清除来源。
- [x] 公开展示标签。火攻等原地公开的本家手牌补 `[明牌]`，已有来源标签时保留来源。五谷丰登展示区的牌按牌号关联后续入手。私有看牌和队友手牌查询不会触发公开标签。
- [x] 效果标签单独判断。顺机、夺炁等按技能或状态显示，游戏已有的标记继续由原生界面显示。
- [x] 袁姬的镜花、水月优先读取新版客户端的原生牌标记状态。旧客户端读取技能牌名单。手牌重排或原生状态重绘时同步，已有原生标签时去重。摸牌不清除已有的来源记录，牌离手时清除。
- [x] 袁姬节言从牌堆摸出并公开的牌显示 `[节言]`。族杨修用捷悟公开自己手里的牌显示 `[捷悟]`，已有来源标签保留。捷悟只给技能发动者看的手牌不加公开标签。
- [x] 心幽标签由游戏原生显示。小抄不再额外生成心幽效果标签或同名来源标签。
- [x] 顺机标签。按本家技能和本局已用牌的技能号显示 `[顺机]`，响应技能状态更新。牌对象缺少技能号时读取牌配置。
- [x] 夺炁标签。手牌、装备和技能选牌读取明牌引擎已记录的“炁”。独立控件在原生标签旁显示，弹层在牌面提供第二标签样式时优先使用该样式。
- [x] 捷悟选牌窗口。按捷悟移牌记录的卡号标来源，窗口打开和切换时重刷，回合开始时清掉上一回合记录。
- [x] 牌堆顶、牌堆底和弃牌堆弹层。显示持续的“炁”，随开关和牌堆数据更新。
- [x] 明牌弹层。读取已展示的原生标签，并按开关合并小抄记录。
- [x] 统一开关联动。刷新手牌、装备、技能窗口和已打开的弹层，关闭时保留游戏原生标签。
- [x] 暂停此前的个性化标签显示。椒遇和弹雀不再由此开关额外绘制。
